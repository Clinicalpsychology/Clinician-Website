🚀 GETTING STARTED (Quick Summary)
═══════════════════════════════════════════════════════════════════════════════

1. SET UP POSTGRESQL
   $ createdb psychologist_directory
   $ psql psychologist_directory < database/schema.sql

2. CONFIGURE ENVIRONMENT
   $ cp frontend/.env.local.example frontend/.env.local
   $ cp backend/.env.example backend/.env
   (Edit files with your settings)

3. START DEVELOPMENT
   
   Terminal 1 - Frontend:
   $ cd frontend && npm install && npm run dev
   → Frontend: http://localhost:3000
   
   Terminal 2 - Backend:
   $ cd backend && npm install && npm run dev
   → Backend: http://localhost:5000
   → API Health: http://localhost:5000/api/health

4. VERIFY SETUP
   ✓ Frontend loads at localhost:3000
   ✓ API responds at localhost:5000/api/health
   ✓ Database tables created in PostgreSQL

See QUICKSTART.md for detailed instructions!
